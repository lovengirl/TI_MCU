# FW 시험판 검증 결과

기준일: 2026-11-01 (한국 시간)

## 결과

| 검증 | 결과 |
|---|---|
| TI SysConfig CLI | 오류/경고 없음, 정보 메시지만 출력 |
| TI Arm Clang 직접 빌드 | PASS, `.out`/`.hex` 생성 |

| MCU 다운로드·실물 시험 | 수행하지 않음 |

직접 빌드 메모리 사용량: Flash 13,792 bytes / 128KB, SRAM 5,614 bytes / 32KB (2KB 스택 예약 포함). 스택 최대 사용량의 실측은 수행하지 않았습니다.

## 내부 검증의 한계

ARM 에뮬레이션은 TI 컴파일러로 생성한 측정 코어를 실행하고 ADC 데이터/하드웨어 동작은 모의 HAL이 제공합니다. 실제 MSPM0 주변장치 시뮬레이터가 아닙니다. UART 파형, DMA 이벤트의 실제 타이밍, 광학 신호, DAC settling, 실제 Watchdog 리셋, 실물 보드의 전원/클록 동작은 보드 시험이 필요합니다.

13 시나리오: 단발 전체 스캔, 히스테리시스, 설정 적용 경계, 잘못된 설정 거부, 일반 정지, 오류/복구, ADC 포화, 극성/이득/오프셋, 잘못된 이벤트, 버퍼 소유권, 잘못된 ADC 데이터, 각 단계 긴급 정지, 100프레임 연속 운전.

35 정적 검사: 주요 GPIO 물리 핀, 80MHz 설정, ADC0/PA27, 매 샘플 이벤트 트리거, DAC/PA15, DMA 데이터폭·주소 증가, SPI 불필요 CS 핀 미할당, WWDT 설정, 2KB 스택, 주요 IRQ 벡터, Flash/RAM 적재 범위, BCR/BSL 설정 데이터 없음.

## 시험판 범위

20채널 선택 회로·광량 제어·ADC 수신 경로가 블록도의 가정대로 연결되어야 합니다. SPI 핀은 예약 상태이며 CC-Link IE TSN 프로토콜은 포함하지 않습니다. 설정은 RAM 전용이며 전원 재투입 시 기본값으로 돌아갑니다. 자동 광량 보정과 Flash 저장은 이 시험판에 포함되지 않습니다.

사용자 보드 시험 순서는 README의 UART 명령 및 최초 시험 절차를 참고하십시오.
